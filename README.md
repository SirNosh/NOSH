# NOSH Research

Networked Orchestrated Science Harness (NOSH) is a local-first research operating environment for reproducible ML work.

The implementation follows the product and engineering specification in ordered phases. The current milestone provides the Phase 0 architecture and security baseline plus the Phase 1 control-plane foundation.

## Development

Use Node 22 and pnpm 10:

```sh
pnpm install
pnpm test
pnpm typecheck
```
